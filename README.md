# 极简禅意 · 小游戏合集

> 6 款白底黑线极简风格 HTML 小游戏，单文件零依赖，Esc 一键退出。
> 从炎黄到现代，从墨海到棋盘，禅意尽在这些一笔一画之间。

## 设计理念

- **白底黑线**：留白即禅意，简约即大道
- **单文件零依赖**：每个游戏都是一个 HTML 文件，浏览器直接打开即可游玩
- **原生 Canvas**：不依赖任何游戏引擎，纯粹的手写 Canvas 渲染
- **Esc 退出**：随时按下 Esc 返回标题或退出游戏

## 技术栈

- HTML5 Canvas 2D 渲染引擎
- Vanilla JavaScript（ES6+）
- Web Audio API（部分游戏音效）
- localStorage（分数存档）
- 零外部依赖，零构建步骤
