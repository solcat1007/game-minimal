# 极简禅意 · 小游戏合集

> 6 款白底黑线极简风格 HTML 小游戏，单文件零依赖，Esc 一键退出。
> 从炎黄到现代，从墨海到棋盘，禅意尽在这些一笔一画之间。

## 设计理念

- **白底黑线**：留白即禅意，简约即大道
- **单文件零依赖**：每个游戏都是一个 HTML 文件，浏览器直接打开即可游玩
- **原生 Canvas**：不依赖任何游戏引擎，纯粹的手写 Canvas 渲染
- **Esc 退出**：随时按下 Esc 返回标题或退出游戏

## 技术栈

- HTML5 Canvas 2D 渲染引擎
- Vanilla JavaScript（ES6+）
- Web Audio API（部分游戏音效）
- localStorage（分数存档）
- 零外部依赖，零构建步骤

## v2.0 更新说明

- **首页升级**：游戏卡片悬停动效（上浮 + 阴影 + 描边生长）、通关成就系统、累计游戏时长统计（均存于 localStorage，可一键重置）。

- **棋影**：新增**三档 AI 难度**（禅定 / 对弈 / 入神），困难档采用位置权重 + 两层前瞻搜索。
- **彩蛋引擎 v2.0**：6 款游戏 + 首页全部注入统一彩蛋协议，每款游戏附带专属彩蛋。
- **PWA**：Service Worker 缓存升级至 v2，manifest 更新。

## 彩蛋秘籍

全站通用的隐藏入口（每款游戏与首页均支持）：

| 操作 | 效果 |
|------|------|
| `↑ ↑ ↓ ↓ ← → ← → B A` | 全屏彩带烟花，并触发当前游戏的**专属彩蛋** |
| 连点标题 5 次 | 打开 SOLCAT 开发者模式面板 |
| 输入 `solcat` + 回车 / `Ctrl+Shift+T` | 切换赛博朋克隐藏主题 |
| 打开控制台 | 查看 ASCII 署名与解锁提示 |

各游戏**专属彩蛋**（Konami 秘籍触发）：

- 墨涌：墨圣降临，金墨护体 900 帧
- 字坠：天降「禅」字雨，输入 `z` 击碎
- 一笔禅：自动一笔完成当前关卡
- 弹墨：全场砖块一击即碎
- 棋影：AI 进入「禅定」简单模式
- 碎镜：碎片自动归位

> 通关成就和游戏时长会记录在浏览器本地，首页可查看进度。按上述秘籍可快速体验各游戏特效。
